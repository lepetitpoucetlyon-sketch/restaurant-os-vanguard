# 🏛️ MANIFESTE NEXUS : Restaurant OS (V15.5)

Ce document est la Source de Vérité pour l'orchestration stratégique de Restaurant OS. Il définit les rôles et les limites de chaque outil pour garantir une efficacité maximale et une isolation hermétique des contextes.

## 🧬 Principes Fondamentaux

1. **Isolation Hermétique** : Antigravity opère en "Fenêtre Stratégique". L'utilisateur opère en "Fenêtre Tactique". Aucune interférence de contexte sans le tag `[SYNC]`.
2. **Ancrage Production** : Le projet unique autorisé pour toutes les opérations est `kitchen-os-gastro`. Toute référence à `minuscule-lab` est considérée comme une erreur critique.
3. **Symétrie des Experts** : Les outils (Kilo, Kombai, OpenCode, Graphify) sont répartis par domaine de compétence pour éviter les conflits d'IA.
