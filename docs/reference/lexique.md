# 📖 Lexique Souverain - Restaurant OS (Grade X)

Ce document réunit l'intégralité des termes techniques, architecturaux et conceptuels utilisés au sein de l'écosystème Restaurant OS.

---

### 🏛️ 1. Gouvernance & Architecture (Grade X+)

* 🛰️ **Nexus** : Le nom de code de la plateforme globale et de son noyau central ultra-résilient.
* 👑 **Suzerain** : Le rôle du MCC en tant qu'autorité suprême dictant les lois à toute la flotte.
* 🏰 **Vassal** : Une instance locale (un restaurant) qui obéit aux ordres et aux schémas du Suzerain.
* 🎗️ **Omphalos (Nexus Bridge)** : Le "cordon ombilical" vital reliant physiquement le MCC aux sites locaux.
* 🛡️ **Grade VI / X / X+++** : Niveaux de certification d'excellence garantissant une pureté architecturale totale.
* 🚧 **Physical Enforcement (IA de Barbelés)** : Règles de build strictes empêchant physiquement toute dérive architecturale.
* 🧵 **Suture Phase** : L'acte chirurgical d'intégration et d'alignement des types lors de l'ajout de nouvelles fonctions.
* 🧬 **Sovereign Pillar** : Modules cœurs (Ops, Finance, Compliance) soumis à une rigueur technique absolue.
* 🌐 **GraphOS** : Le graphe de données universel connectant tous les nœuds du système sans friction.
* ☢️ **Nuclear Purge** : Nettoyage atomique instantané de la mémoire lors d'un changement de contexte restaurant.

### 🛰️ 2. Connectivité & Ponts (Bridges)

* 🛰️ **Nexus Bridge** : Le lien de commande résilient assurant la synchronisation temps-réel avec le Cloud.
* 💳 **Financial Nexus Bridge** : Pattern standardisé pour l'intégration sécurisée des paiements au grand livre.
* 🕒 **Master Bridge** : Service poussant les configurations signées et horodatées sur toute l'infrastructure.
* 🌡️ **HACCP Telemetry Bridge** : Pont de données transformant les risques sanitaires locaux en alertes stratégiques.
* 📡 **Axiom Bridge** : Liaison haute performance pour la télémétrie technique et le logging de structure.
* ⚛️ **Atomic Bridge** : Hooks de niveau Grade VI (useSettings, useUI) servant de proxys vers le noyau Nexus.
* 📍 **Digital Twin Routing** : Résolution des chemins de persistance basée sur l'isolation des "Jumeaux Numériques".
* 🎛️ **Sovereign Switchboard** : Panneau de contrôle des permissions globales géré directement depuis le MCC.

### 🧠 3. Intelligence & État (Hermes & Agents)

* 🤖 **Hermes Engine** : L'orchestrateur multi-agent gérant l'intelligence croisée entre les domaines.
* 🗺️ **Atlas / Themis / Cronos** : Agents Vanguard dédiés respectivement à la Cartographie, la Validation et le Temps.
* ⚡ **Zeus** : Agence de haut niveau spécialisée dans la détection d'anomalies inter-domaines.
* ⚖️ **Inquisiteur** : Agent de QA effectuant des audits structurels pour débusquer les fuites de mémoire.
* 🧠 **MacroBrain** : La couche d'intelligence centrale pour les prévisions stratégiques à grande échelle.
* 🕸️ **Jotai Mesh** : Maillage d'atomes légers remplaçant les structures d'état centralisées et lourdes.
* ⚛️ **WritableAtom** : Atome Jotai strictement typé garantissant la sécurité des mutations d'état face aux attaques (Grade X).
* 🗄️ **Slotted Atoms** : Structure de mémoire où les données sont logées dans des compartiments interchangeables.
* 🧠 **GlobalRegistry** : Le cerveau orchestrant le cycle de vie des slots de mémoire du système.
* 📉 **O(1) Memory** : Garantie que l'empreinte mémoire reste constante, peu importe la taille de la flotte.
* 👻 **Shadow Context** : Simulation d'isolation matérielle pour garantir l'étanchéité totale des sessions.
* 🧬 **DNA Injector** : Injection dynamique de règles métier dans les agents IA via le cockpit du MCC.
* 🧠 **LightRAG Local** : Graphe de connaissance privé et isolé par Vassal, garantissant le Zero-Leak.

* 🐒 **ChaosMonkey (Chaos-V5-Adversarial)** : Moteur de stress-test sandboxed simulant des rushs (Zombie Rush), des dérives (Drift) et des anomalies mathématiques.

* 🎻 **SinfoniaGradeXProof** : Simulateur ultra-complexe prouvant l'efficacité des calculs croisés autonomes (Finance/HACCP) en une fraction de microseconde.
* 🎭 **Simulacra Adapter** : Couche de simulation haute fidélité permettant de tester le système sans base de données.
* 🛰️ **Nexus Pulse Orchestrator** : Point central où tous les réflexes croisés et les battements de cœur sont monitorés.
* ⚡ **Performance Engine (Lumière de Brigade)** : Orchestrateur adaptatif ajustant l'UI selon la puissance du matériel.
* 💡 **Brigade Light** : Mode d'interface dépouillé et ultra-rapide pour les terminaux de cuisine.
* 🧠💸 **Finance Reflex** : Réactions comptables automatiques déclenchées par des événements système (ex: Pertes HACCP).
* 🛰️ **SelfHealingEngine (Silent Healing)** : Mécanisme autonome de réparation en arrière-plan sans intervention humaine.

### 🔒 5. Conformité & Ingénierie des Données

* 🐉 **Slayer (Omega Ingestion)** : Moteur de migration massive pour absorber les données des systèmes legacy.
* 🧼 **Data Digester** : Service de normalisation et de décontamination des données avant ingestion.
* ☣️ **Decontamination** : Processus de nettoyage des entrées brutes pour garantir l'intégrité du noyau.
* 📦 **Industrial Chunking** : Découpage optimisé des flux de données pour une persistance massive et stable.
* 🔒 **NF525 Sealing** : Scellage fiscal par hachage cryptographique Post-Quantum (SHA-256).
* 📖 **Sovereign Ledger** : Le registre inaltérable et sacré de toutes les transactions financières.
* 🔗 **Blockchain Ledger Service** : Journal d'audit transparent et immuable pour une traçabilité totale.
* 🔢 **Sovereign Math** : Bibliothèque de calcul de haute précision (Microunits) pour la sécurité fiscale.
* 💰 **Microunits** : Entiers représentant la monnaie (ex: cents * 1000) pour bannir les erreurs de virgule flottante.
* 🚨 **HACCP Sentinel** : Alertes automatisées lors du dépassement des seuils de sécurité alimentaire.
* 🏛️ **LegalArchiveService** : Pont de Grade IX pour l'archivage légal à long terme des données scellées.
* 🛂 **Pulse Sanitizer** : "La Douane". Service de décontamination bloquant les PII et anonymisant les données avant leur envoi au MCC.

### 🏗️ 6. Contrats & Techniques

* 🧬 **Sovereign Node** : Le contrat universel que tout objet métier doit implémenter pour être reconnu.
* 🧪 **Sovereign Field / Value** : Les types de données fondamentaux constituant le génome du Nexus.
* 🔢 **OperationalIdentity (STX_ALPHA à LAMBDA)** : Codes de résolution des chemins de données souverains.
* 🎭 **Nexus.adapter** : L'interprète universel permettant à l'UI de dialoguer avec le moteur sans le polluer.
* 🚧 **SovereignGuard** : Barrière de sécurité empêchant toute fuite de données entre les instances.
* 🔏 **Smart Seal** : Gouvernance automatisée des exports de dossiers et de la visibilité des modules.
* 🗝️ **Genome Validator** : Le gardien vérifiant chaque écriture système pour prévenir toute corruption.
* 🚨 **SovereignError** : Contrat d'erreur structuré permettant une résolution intelligente par l'IA.
* 🛡️ **Guard-First Listener** : Pattern architectural garantissant que les autorisations (SovereignGuard) sont toujours validées *avant* l'ouverture d'un flux de données temps réel (onSnapshot).
