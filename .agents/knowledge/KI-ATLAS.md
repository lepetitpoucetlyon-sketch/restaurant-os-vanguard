# KI: The Atlas Nexus (Architectural Truth)

## 🎯 Purpose
The Atlas Nexus is the binary source of truth for the **Restaurant OS Grade X** architecture. It is generated by the **Graphify** tool and stored in `graphify-out/graph.json`. Its primary role is to prevent architectural drift and ensure that the Singularity maintains its structural integrity.

## 🧱 Structure
- **Nodes**: Represent files, functions, and classes.
- **Communities**: Represent logical clusters identified by community detection algorithms in the graph.
- **Edges**: Represent dependencies (imports, calls).

## 🛠️ Usage (Antigravity-Audit)
To verify if a change respects the architecture:
```bash
node scripts/antigravity-audit.js src/path/to/file.ts
```

### Critical Rules
1. **Core Sanctity**: Files in `src/engines/core` or `src/domain` must NEVER depend on `src/components` or `src/view`.
2. **Cluster Respect**: Adding a function to a file should logically belong to the community assigned to that file in the latest scan.
3. **The Suture**: When creating new adapter layers, ensure they are mapped to the infrastructure community.

## ⚙️ Maintenance
A new Atlas scan should be performed after every major architectural shift using:
```bash
npm run atlas
```
This requires access to the `restaurant-os-graph` workspace.
