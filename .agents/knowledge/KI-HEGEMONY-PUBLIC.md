# KI: Hegemony Strategy (Public) [GRADE X]

## 🎯 Identity & Mission
The **Public Hegemony** is the external shield. It handles Landing, Auth, and Documentation.

## 🛡️ Isolation Protocol (Sovereign Guard)
- **Strict One-Way Flux**: Can import from `SharedKernel` (Leaf-Node). Cannot import from `(backoffice)`, `(hr)`, or `(admin)`.
- **Anonymization Proxy**: Must interact with the database only through hardened adapters that enforce absolute PII protection.
- **Zero-Trust Docs**: Documentation is static and must not contain any reference to internal server-side routes or secrets.
